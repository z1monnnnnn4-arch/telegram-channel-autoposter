# TG Channel Poster

Автоматическая ежедневная публикация постов в сотни/тысячи Telegram-каналов с одного аккаунта.

## Как это работает

1. **Telethon (user API)** — постит от вашего аккаунта во все каналы, где вы владелец/админ.
2. **Aiogram (bot API)** — панель управления: `/status`, `/sync`, `/post`.
3. **APScheduler** — автозапуск каждый день в заданное время.
4. **SQLite** — список каналов, логи, статистика.

## Быстрый старт

### 1. Установка

```bash
cd d:\tg_bot
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Настройка

```bash
copy .env.example .env
```

Заполните `.env`:

| Переменная | Где взять |
|-----------|-----------|
| `API_ID`, `API_HASH` | https://my.telegram.org/apps |
| `PHONE` | Номер аккаунта с каналами |
| `BOT_TOKEN` | @BotFather |
| `ADMIN_IDS` | Ваш Telegram ID (@userinfobot) |

### 3. Контент

- Тексты: `content/texts/*.txt` (выбирается случайный файл)
- Картинки: `content/images/*.jpg` (случайный набор, до 10 шт.)
- `PHOTOS_PER_POST=9` — как у конкурентов на FunPay

### 4. Первый запуск

```bash
python main.py
```

При первом запуске Telethon попросит код из Telegram и, возможно, 2FA-пароль.

После запуска в Telegram-боте:

```
/sync   — подтянуть все ваши каналы в базу
/status — сколько каналов, сколько постили сегодня
/post   — запустить рассылку вручную
```

## Масштаб

| Каналов | POST_DELAY_SEC | Время рассылки |
|--------|----------------|----------------|
| 100    | 4              | ~7 мин         |
| 500    | 4              | ~33 мин        |
| 1000   | 4              | ~67 мин        |
| 5000   | 4              | ~5.5 ч         |

При `FloodWait` бот автоматически ждёт и повторяет.

Рекомендации:
- `POST_DELAY_SEC=4` и выше для больших объёмов
- Не запускайте `/post` параллельно с авто-рассылкой
- Каналы без прав на постинг деактивируются автоматически

## Структура

```
tg_bot/
  main.py           — точка входа
  poster.py         — логика рассылки
  admin_bot.py      — команды управления
  scheduler.py      — ежедневный cron
  database.py       — SQLite
  content_loader.py — тексты и фото
  content/
    texts/
    images/
  data/             — база, логи, сессия (создаётся автоматически)
```

## Важно

- Все каналы должны быть на **одном** Telegram-аккаунте (или доработайте под несколько сессий).
- Это инструмент для **ваших** каналов. Массовый спам чужих каналов — нарушение правил Telegram.
- Храните `.env` и `data/*.session` в секрете.
